# Circuits functional parity roadmap

## v0.1 editor foundation
- SVG design surface, palette, component placement, pin wiring, undo/redo and browser persistence
- Basic LED / resistor / battery demo, code editor for Arduino text (not instruction execution)
- TypeScript strict checks, unit tests, Vite build, GitHub Pages pipeline

## v0.2 electrical editing
- Breadboard contact insertion, snap, wires with bendpoints, better selection, schematic connectivity graph

## v0.3 simulation
- Netlist IR, modified nodal analysis, DC/transient solvers, verified component models, multimeter and oscilloscope

## v0.4 Arduino
- Sandboxed AVR-compatible runtime, compile, GPIO, timers, PWM, ADC, serial monitor, libraries subset

## v0.5 parity
- Blocks/Text programming, schematic synchronization, catalogue expansion, collaboration and measured reference parity.

**Current status is a prototype, not 1:1 parity.** No Autodesk affiliation or copied proprietary assets.
