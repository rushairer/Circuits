## 第一批：导线几何

`createPinResolver` 为一次绘制建立元件快照，按需计算并复用真实引脚坐标，避免每根导线的两个端点都线性扫描元件数组。每次重新绘制都重新创建；不能跨移动、旋转、撤销或导入复用旧快照。返回坐标副本，端点预览不能污染其他导线。

`paintCrossingWires` 复用已生成的路由顶点，减少重复生成正交路径。超过原有 720 线段的装饰预算时，在分配线段对象和索引之前退回普通导线；导线本身仍完整显示、可编辑。

小场景继续直接扫描。较大且稀疏的场景使用包围盒树过滤无关线段；密集场景通过固定采样回退直接扫描。当前采样为 24 个线段，至少 256 个线段、采样包围盒重叠比例低于 25% 时使用索引。这是计算策略，不影响显示或连接语义。

每根导线按真实路由顺序处理交叉点，满足原有最多 24 个跳线拱后停止发现后续交叉点。不改变拱的选择顺序，不减少原有上限，不增加隐式电气节点。

## 第二批：指针手势

`src/core/pointer-session.ts` 只管理瞬态触点与拥有者，不接触电路、DOM 或世界坐标。`src/ui/pointer-input.ts` 负责浏览器事件、捕获、目标解析与兼容点击；`src/main.ts` 保留具体编辑操作。

一次编辑只有一个 pointerId 可以移动或提交。第二个触点进入时取消当前预览，所有原有触点抬起后才接受新编辑；不能把操作转交给剩余手指。该策略也避免手指与笔同时修改电路，但不是硬件级掌托识别。双指平移/缩放尚未实现。

触控与笔在稳定的 `#app` 上捕获，不把捕获绑到重绘时会被替换的引脚、`#board` 或 `#scene`。松手目标由实时屏幕位置反查，不能用捕获后的 event.target 作为目标引脚。画布外松手不能连接到工具栏背后的几何位置。

触摸移动阈值为 8 CSS 像素，鼠标/笔为 5 CSS 像素；未越过阈值的抖动不会拖动元件或创建撤销记录。该阈值只区分点按和拖动，不是折点吸附滞回。松手时补处理最后一个位置样本，避免浏览器省略末次 move 时保存旧位置。

触控/笔点按在松手时处理一次，随后抑制本次手势的兼容 click；鼠标仍保留原生单击和双击。键盘/辅助技术激活、原生工具栏、输入框与下拉框不走该去重逻辑。笔侧键和橡皮擦按钮不能当作左键开始编辑。

Escape、pointercancel、丢失捕获、窗口失焦和页面隐藏统一清理手势。元件和折点恢复按下时的工程快照；画布平移恢复原相机位置；不保存预览、不增加撤销记录。折点移动通过 `moveWireWaypoint` 不可变更新，继续校验坐标边界。窗口无编辑手势时失焦不重绘，防止替换正在使用的文件输入或丢失尚未提交的文字。复位后迟到的 pointerup 不能通过兼容 click 再启动接线。

## 第三批：交叉和重叠导线精确选择

`src/core/wire-picking.ts` 复用引脚解析和实际路由顶点，按投影到可见导线中心线的 **CSS 像素**距离排序；半径 9px，缩放时保持相同屏幕命中范围。透明 SVG 17px 命中层不影响几何排序；普通导线同距离候选使用工程原始顺序，不随选中导线临时抬高的绘制层级变化。**实际命中的彩色跳线拱**若与底层路由中心线偏移超过 3px，则优先选择这段真实可见的弯曲线条，兼容原有跳线拱点击与拖动；此例外不扩大透明命中范围，也不产生电气连接。

对真正靠近的候选（与最近线距离差不超过 3px），在同一位置约 7px 范围内、1.6 秒内重复点击可循环切换；Alt + 点击也能立即切换。第二次原生双击仍使用当前选中候选添加折点。候选和循环状态均为 UI 暂态，不写工程 JSON、不创建额外电气节点、不增加撤销记录。

点按、双击添加折点与线段拖拽共用相同的几何候选；如果当前已选线与最近线的距离差不超过 3px，起拖手势优先调整该选中线。真实器件、插孔、引脚、折点和端点手柄继续优先处理。拖动依旧复用原有不可变编辑及单步撤销流程。

`tests/wire-picking.test.mjs` 另外覆盖交叉排序、图层独立、缩放阈值、传统斜线路径、退化点与候选循环；`e2e/wire-picking.spec.ts` 覆盖在实际页面中点击交叉、重叠、拖动与缩放。保留旧的交叉跳线及 DOM 分层回归。屏幕距离为数学几何最近线，并非原站官方 hit-testing 规范；尚未开展原版登录态对比。

## 第四批：折点拖动吸附滞回

现有折点拖动接入 `src/core/waypoint-snap.ts`。只采集当前导线的真实端点和其余折点作为对齐参考，按手势建立快照，不随编辑预览漂移。优先级依次为二维真实端点、对齐参考线、网格；对齐并不创建新电气连接。网格开关仅控制网格吸附，不关闭端点/折点对齐。

屏幕像素阈值：对齐吸入默认 6px，脱离 11px；网格吸入/脱离被可见网格间距进一步限制，防止缩小画布时跨格粘滞。X、Y 轴对齐分别保存瞬态状态，指针结束或取消后清除。辅助线 `pointer-events:none`，只存在于编辑预览，不写入工程、不增加撤销记录；完成一次折点拖动仍为单次 undo，取消时恢复指针按下时的工程快照。

`tests/waypoint-snap.test.mjs` 检查阈值、脱离滞回、低缩放网格、对齐优先和异常输入；`e2e/waypoint-snap.spec.ts` 验证真实页面临时辅助线、Esc 回滚、电气端点不变与单步撤销。新建折点、整段拖动仍保留既有行为；此批不代表全编辑器吸附规则完成。

## 第五批：持续拉线与键盘缩放（原版参考核对）

**可核对的原版操作**：Autodesk 官方《[Guide to Tinkercad Circuits](https://www.tinkercad.com/blog/official-guide-to-tinkercad-circuits)》说明二维工作台可滚轮、触控板和 Command +/- 缩放，并可用 F 适应元件；[公开操作教程](https://resources.finalsite.net/images/v1722986325/brightonk12com/rlz6hzm1rx6tefnd33bp/01tutorialtinkercadelectricalseriescircuita.pdf) 描述从引脚开始拖线、点击沿途位置增加弯角，直到接上另一器件。教程来自独立教学资料，并非 Autodesk 精确定义的交互规范。

旧实现从引脚拖动到**画布空白处松开**会清空整个布线草稿。第五批使空白处松开保留临时路线（不入 JSON、不进 undo），随后可继续移动指针、点击添加多个世界坐标转角，再点击合法的目标引脚提交；空白落点本身不自动变成一个折点。画布外松开仍取消，Escape、pointercancel、失焦以及第二根手指介入仍是原子取消。

Command/Ctrl + `=`/`+` 和 `-`/`_` 操作画布缩放，保留视图中心；不劫持输入框、文本编辑及系统可访问性焦点，不改元件和导线坐标。Wiring 草稿保留在缩放过程中。

浏览器检查：`e2e/wire-route-parity.spec.ts` 覆盖空白处松手后多次交互、端点完整与单步撤销、取消/画布外阻断、缩放与输入焦点。必须和现有三引擎端点改接、跳线拱、触控/笔取消回归一起放行。

**未确认**：原站私有登录态的具体拐弯算法、导线路径平滑/半径、所有键盘修饰组合、多点触屏手势及像素级 UI。这批是基于可公开验证资料的功能对齐，不宣称整体 1:1。

## 第六批：导线 Shift 多选及批量操作

Autodesk 官方《Tinkercad Circuits Guide》在 General Tips 中确认 Shift 多选对象；独立教程明确写出 Shift + click 可同时选择多根导线并从顶部调色菜单改变颜色。本项目原先仅在元件选区实现 Shift，多根导线无法统一改色。

编辑器采用 `selectedWireIds` 临时集合；普通点击选择单根，Shift + 点击增减候选，选中集合保持高亮且不写入工程。交叉点依然优先采用第五批之前的几何候选逻辑，真实插孔优先；同一手势如转为线段拖拽则收敛到单根导线，防止批量选择状态误移动。

顶部导线调色板对整个选中集合调用纯函数 `recolorWires`；批量删除调用 `removeWires`。它们只按稳定 wire ID 不可变修改颜色或移除导线，其他电气端点、折点、元件和插孔接触不变，整个用户动作只记入一个 undo。切换元件/工程、Esc 或空白点击及时清除导线集合，输入与键盘快捷键规则保持不变。

`tests/wire-batch.test.mjs` 检查不可变更新、netlist 端点归属、空操作与删除边界；`e2e/wire-multi-select.spec.ts` 检查真实画布 Shift 组合、高亮、颜色快捷键、删除与单步撤销。原站登录态的具体高亮颜色与 Inspector 版式仍待视觉比对。

## 第七批：原版导线颜色键位顺序

Autodesk 官方指南确认导线支持 0–9 数字快捷键。独立的历史原版编辑器操作记录具体说明了键位顺序：**1 黑、2 红、3 橙、4 黄、5 绿、6 青、7 蓝、8 紫、9 粉、0 棕**；灰、白可从下拉菜单选择但无数字标签。原实现误将 0 设为黑、1 设为红，整列偏移。

调整 `src/core/wire-colors.ts` 的数字键查表与 12 色下拉显示标签，不改变已有工程中的颜色十六进制值、默认绿色、其他用户自定义值、端点 ID、线路几何或撤销语义。键盘快捷键仍只在选中导线（单根或 Shift 批量）或绘制草稿期间生效，输入/文本框不劫持。

[历史参考：Tinkercad Circuit 界面操作记录](https://lonelyengineer.tistory.com/2086)（2021）。现代登录态原版是否有调整键位仍需要人工核验；不得把历史资料充当 2026 年的认证像素/快捷键比对。

## 第八批：与原版对齐的注释工具（N / Shift+N）

**来源**：Autodesk 官方《[Guide to Tinkercad Circuits](https://allpathengineering.org/wp-content/uploads/2023/08/tinkercad-guides_circuits-Printable.pdf)》第 20–21 页明确记录：N 创建 Note、Shift+N 隐藏/显示 Note，注释可在电路图中移动，不应遮挡重要元件。原版截图呈现为电路上方的浅色圆角文本标签。

此批实现工具栏的“注释”与显隐按钮及键盘 N / Shift+N，选中后右侧文字编辑（自动焦点）、实时 SVG 纯文本预览、双击回到编辑器、鼠标/触控笔单指拖动、Delete 与键盘方向键微移。单击画布放置一张注释，拖动注释保持世界坐标，Escape / Pointer Cancel / 多指介入必须丢弃临时拖动。显示开关仅为瞬态 UI 状态，不覆盖或删除已有注释，且应影响 F 自动适应视口中的可见注释范围。

工程继续为 schema-v2，新增**可选** `notes: {id,x,y,text}[]`，旧 JSON 无需迁移。每个文本最长 500 UTF-16 字符，最多 120 条，ID 独立且无重复，坐标有限且落在 ±100000 世界单位之内；导入不合规直接拒绝。文本始终是纯文本，SVG 不执行任何 HTML、外部脚本。所有注释操作通过不可变快照写入同一套 undo/redo；一次移动或文字编辑只增加一条历史，未完成移动不入工程。注释不是元件，也没有 terminal/net 身份，`buildNetlist`、电气求解与 Arduino 受限预览不应受注释创建或修改影响。

`src/core/notes.ts` 为纯数据操作，`src/ui/note-render.ts` 为有界、安全转义的视觉渲染；`tests/notes.test.mjs` 检查校验、XSS 字符串、原有网络关系、缩放适应和不可变操作；`e2e/notes.spec.ts` 跑 Chromium / Firefox / WebKit 的放置、编辑、显隐、撤销、跨事件取消、仿真保持及恶意导入拒绝。

**边界**：这是根据官方公开文档落地的真实注释功能，不是已经对照 2026 年登录态编辑器的逐像素或弹窗布局复制。原版注释的精确字体、可变尺寸、多选/分组和触摸硬件手势仍待独立检验。

## 回归与证据

第一批的 `tests/wire-performance.test.mjs` 保留 25 项检查，包括 17 组 alpha.10 绘制摘要。旧版参考为提交 `813d676dbfa9639b77a582b9e6f884f122773392`；不能在新实现失败时直接重写旧版摘要来放行。

`e2e/wire-performance.spec.ts` 继续覆盖 300 元件、2000 导线的导入、显示、缩放、微移、端点保持和单步撤销。它不是 FPS 测试。

第二批增加 14 项纯逻辑测试（含继承事件属性快照回归），以及 `e2e/pointer-input.spec.ts`、`e2e/pointer-boundaries.spec.ts` 的 26 个浏览器场景。覆盖真实触摸点按、缩放后的接线、元件/折点移动、面包板端点改接、相机平移、最终采样、四类取消、多指介入、迟到事件、笔侧键、表单保护和单步撤销。

另有 `e2e/pointer-recovery.spec.ts` 的 3 个场景检查尚未拖动就取消的引脚操作不会污染下一次元件拖动，第二批合计 29 个浏览器场景。

三引擎运行同一组确定性 PointerEvent 轨迹，并使用 Playwright 的原生触摸点按。仅 Chromium 通过 CDP 注入原生触摸/笔拖动；该单项在 Firefox/WebKit 明确跳过，不把合成事件冒充平台捕获验证。所有原有鼠标、键盘、仿真与大场景测试仍必须通过。

桌面 1440×900 和平板尺寸 1024×768 的触控接线截图保存在 CI 的 `pointer-interaction-evidence` artifact（7 天）。当前提交的 Actions 结果是放行依据，文档中的“已接入”不是未经测试的发版承诺。

## 可复现命令与边界

```sh
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run bench:wires
npm run bench:wires -- --baseline /path/to/alpha10/.test-dist/core/wire-crossings.js
```

几何基准使用固定种子，覆盖小场景、600 线段稀疏布局、720 线段密集交叉、2000 根普通导线及 2000 根各含 32 折点的导线。先预热，再交替执行比较对象，报告 40 个样本的 p50/p95，以及 Node、CPU 和平台信息。

**几何耗时不包含 DOM、绘制、事件处理和求解器，不能宣传为编辑器 FPS。** 不把共享 CI 机器的绝对耗时设为不稳定的单测门禁。

原生 Safari、实际触屏/笔设备、系统掌托/中断、窄屏手机和原版登录编辑器的逐项对照仍待独立验收。选择、吸附参考线与指针状态必须保持瞬态；端点 ID、颜色、世界坐标折点和单步撤销继续受根目录 AGENTS.md 约束。目标继续是向 Tinkercad Circuits 对齐，没有新的 1:1 或完整设备支持声明。
