# Circuits

[English](README.md) · [架构](docs/ARCHITECTURE.md) · [路线图](docs/ROADMAP.md)

Circuits 是独立开源的浏览器电路设计工作台，使用 **TypeScript + Vite** 开发。长期目标是对标 Tinkercad Circuits 的功能体验，而非复制 Autodesk 专有源码、商标或素材。

> **当前 v0.4.0-alpha.8 是实验性原型，不是已完成的 1:1 复刻。** 仅提供受限 Arduino D13 教学代码预览，不支持通用 AVR/C++ 指令执行，也不是通用 SPICE 仿真器。

## 已实现

- 13 类自绘 SVG 元件：电池、电阻、LED、面包板、Arduino Uno、拨动开关、按钮开关、电位器、电容、蜂鸣器、万用表、串联电流表、舵机
- 画布添加/拖动/旋转/删除、Shift 多选、框选、整体移动、批量旋转与删除、按引脚接线、导线选择与颜色编辑、拖拽重新连接导线端点、可保存的导线折点与网格吸附
- 撤销重做、多工程本地管理（新建、复制、切换、删除）、旧草稿自动迁移、JSON 工程导入导出、缩放、Arduino 代码编辑与受限 D13 Blink 时序预览
- 面包板五孔连通组、电源轨分段及两侧绝缘分隔；电阻与 LED 引脚靠近插孔自动吸附、建立接触，移动后会重新校准接触
- 实验性 MNA 直流求解：**一节电池 + 一只 LED + 电阻网络**（含并联），支持理想双端拨动开关闭合/断开
- 工程文件结构校验及单元测试

**重要限制：** LED 用固定 2V 导通压降近似。可放置的其余元件大多只有可视化与接线能力，不能声称已接入仿真；没有完整 MCU/AVR 运行时或真实仪表；RC 教学波形及 D13 受限代码预览不代表通用硬件仿真。

## 运行与验证

需要 Node.js 22.12+。

```sh
npm install
npm run typecheck
npm test
npm run test:e2e # 首次执行前安装 Chromium、Firefox 和 WebKit 浏览器
npm run build
npm run dev
```

## CI / GitHub Pages

每次提交到 `main` 会自动执行 TypeScript 检查、单元测试和 Vite 构建，并将经过验证的产物保存为 `circuits-dist`。发布到 GitHub Pages 还需要仓库管理员**首次启用 Pages**：

1. 打开 [Settings → Pages](https://github.com/rushairer/Circuits/settings/pages)。
2. 在 Build and deployment 的 Source 选择 **GitHub Actions**。
3. 打开 [Actions](https://github.com/rushairer/Circuits/actions/workflows/ci.yml)，运行 `Quality & Pages` 工作流（或推送新提交）。
4. 只有部署任务成功后，https://rushairer.github.io/Circuits/ 才可视为上线。

## 下一阶段

按 [ROADMAP](docs/ROADMAP.md) 先完善面包板插孔交互、导线编辑、工程模型版本化与端到端测试，再推进真实元件模型、仪表和 Arduino 模拟运行时。项目与 Autodesk / Tinkercad 无关联，代码采用 MIT 许可证。

### 键盘操作

Tab 聚焦元件，Enter / 空格选择当前元件，Shift 组合多选；Ctrl/Cmd+A 全选，方向键移动选中元件，Alt+方向键微移，Delete 删除，Ctrl/Cmd+Z 撤销。

GitHub Actions 同时测试 Chromium、Firefox、WebKit。Linux WebKit 测试不等同于 macOS/iOS 上的真实 Safari 验收。

### 画布导航

滚轮以鼠标光标为中心缩放；直接拖动空白画布、按住空格左键拖动或按鼠标中键拖动可平移；按 Shift 在空白处拖动可以框选。按 F 可缩放到全部元件。底部 +/− 以可视区域中心缩放，「适应」调整视角，不更改电路。

### 实验性非线性直流分析

点击工具栏的「模型：固定 2V」切换到「模型：非线性 DC（实验）」，再点击开始仿真，可观察多只 LED 串并联支路的独立电流、过流提示，以及万用表正负表笔之间的有符号直流电压差。未连接表笔会显示「未连接」而不是伪造 0 V。

该模型仅支持单个理想电池、电阻网络、理想开关和指数近似 LED；LED 曲线只在约 2 V / 20 mA 附近用于教学，不考虑器件温升、击穿或参数离散，不是 SPICE。原始固定 2V 模式保留为默认选项，确保旧工程的结果预期不被悄悄改变。

点击工具栏「示例电路」可以分别创建基础 LED、双 LED 并联、双 LED 串联、9V 万用表四类独立工程，不覆盖当前设计。打开示例时自动选择实验性非线性 DC 模式，再点击「开始仿真」查看读数。

### 发布版本验收

生产 HTML 会写入当前 Git 提交 SHA。Pages 发布成功后 CI 将访问公网核对 SHA，而不只检查页面标题，避免把 CDN 缓存中的旧版本误判为新版本。针对 GitHub Pages 的偶发产物元数据延迟，仅做一次有界重试。

### RC 充放电暂态实验

在「示例电路」中选「RC 电容充电」或「RC 电容放电」，点击「开始仿真」即可查看 0–5 倍时间常数的电容电压曲线，移动「采样时刻」滑块可查看不同时间的电压与电流。电容属性新增电容量（µF）和初始电压（V）输入。工作台根据实际引脚网络求 Rth 和稳态电压，不从图形位置猜测回路。

单电容解析求解器只支持一只理想电容、线性电阻、静态理想开关及零或一个理想电池；多电容另由独立的数值模块支持。电感、开关实时切换与 LED 暂态尚未实现。波形是模型采样，不代表真实时间执行。

### 多电容 RC 数值暂态

新增「双电容并联 RC」和「双电容串联 RC」示例，示例总数目前为 12 个。RC 模式自动对单电容采用解析模型，对 2–6 只电容采用向后欧拉数值积分。可切换电容曲线、调整 0.1–10 秒窗口并拖动时间滑块，查看所选电容的电压和电流。初始时刻电流未计算，明确显示为「—」；存在初始电压冲突、理想电源硬约束矛盾时，拒绝给出不可靠的曲线。电感、实时开关事件、非线性器件及多独立电源依然不支持。

### 虚拟示波器与 RC 电压表

在 RC 暂态模式开始仿真后，点击「▤ 示波器」打开独立的双通道教学波形界面。CH1 展示所选电容的模拟电压，CH2 展示对应电容支路的计算电流（分别缩放）；可切换电容、拖动时间光标并导出带单位的 CSV。多电容 t=0 未求出的电流保留空单元格，而不是虚构为 0。

接入已求解 RC 网络的万用表可显示有符号 RC 电压，包含电容串联路径、表笔反接及电阻网络节点；未连接或跨独立浮置网络时显示「----」和原因。以上均是算法结果可视化，不代表真实硬件测量或完整 SPICE。

### RC 电阻节点电压与数值一致性检查

RC 电压表可测量电阻两端及同一受约束电气网络内的节点压降，利用当前电容采样电压、理想电源和电阻 KCL 进行计算，不靠画布上元件的几何距离猜电位。不同浮置网络、断开的表笔或矛盾电压约束仍明确显示不可测。原有示例「RC 电阻压降测量」，1kΩ 电阻两端的表显电压从 9V 随充电时间衰减，在一个时间常数处约为 3.31V。

多电容 RC 面板新增「检查数值一致性」按钮：以两组内部步长计算并比较最大电压差，提示时间窗口过长导致快速暂态欠采样的问题。该数值只是步长敏感性结果，**不是物理精度评级或误差上界**。检查不会修改用户工程。

### v0.3.0-alpha.7：串联电流表与可配置开关

组件库新增「串联电流表」，采用固定 0.1Ω 分流电阻参与仿真，必须将正负端真实串入电路才能显示有符号 mA 读数。支持实验性非线性 DC 和 RC 模式；一端未连接不显示伪造的零电流。超过 ±200mA 显示 OL 和教学量程警告，不模拟保险丝烧毁。原始固定 2V 模式尚不支持该元件。

拨动开关增加闭合接触电阻参数：默认 0Ω 保持历史理想开关闭合逻辑，可配置 0.1–1,000,000Ω，断开状态不导通。操作开关将从定义好的 t=0 初始状态重新求解，而非模拟波形中途切换。新增三个独立示例：LED 串联电流表、RC 串联电流测量、RC 有损接触开关；现在总共有 12 个。加入 shunt 负载与接触电阻对时间常数影响的解析/数值对照，仍非 SPICE 精度认证。

### v0.4.0-alpha.1：Arduino D13 Blink 受限代码预览

在画布中保留恰好一块 Arduino Uno，打开「〈/〉 代码」，点击「▶ 解析并预览 D13」。默认 Blink 草图可生成确定性 2000ms 周期，在 0–5000ms 光标上观察内置 D13 指示灯随 `HIGH/LOW` 变化。解释器只识别 `void setup()`、`void loop()`、`pinMode(13,OUTPUT)`、`digitalWrite(13,HIGH/LOW)`、有界整数 `delay(ms)` 等极小子集，同时允许 `LED_BUILTIN` 和简单整数常量别名。非支持语句明确报错，完全不使用动态代码求值。

**边界**：这不是 Arduino/AVR C++ 编译器或真正的 MCU 仿真；alpha.2 已限定支持 D13→限流电阻/LED→GND 的真实接线教学模型，仍不能执行串口、其他 GPIO/PWM/ADC 或实时调度。它是预先计算的纯前端教学时序；工程代码发生修改时，旧的预览立即失效，原有 DC/RC 求解保持独立。

### v0.4.0-alpha.2：外接 LED 随 D13 高低电平变化

新增第 13 个示例「Arduino D13 外接 LED 闪烁」，默认配置 Uno D13 → 330Ω 电阻 → LED 阳极、LED 阴极 → GND。打开受限代码预览后，时间光标位于 HIGH 阶段则外接 LED 点亮，LOW 阶段熄灭。电流由电气端点、导线和面包板网络计算，不靠画布上的元件距离猜接线，也不会把运行时结果写进工程 JSON。

GPIO 采用独立的**教学近似输出级**：HIGH 为 5V、LOW 为 0V，串联固定 25Ω 驱动内阻，并调用现有非线性 LED/限流电阻求解器。超过 ±20mA 发出 GPIO 教学电流警告，LED 过流不视为正常发光；LED 反接、端点未连通、缺少限流、D13/GND 短接和独立电池混合供电都提供明确诊断。**25Ω 不是对真实 ATmega328P 的已验证器件参数。** 不支持 AVR 指令、任意 GPIO、PWM、ADC、外接电容瞬态或中断和串口。


### v0.4.0-alpha.3：Arduino 虚拟串口监视器

示例库新增「Arduino 虚拟串口日志」（共 14 个示例）。点击「解析并预览 Arduino」，可静态识别白名单范围内的 `Serial.begin`、`Serial.print`、`Serial.println`，支持固定字符串和整数常量。随着 0–5000ms 时间光标变化，监视器显示确定性日志，允许导出当前可见的 TXT，并提示历史截断。仅用串口的草图无需配置 D13；D13 与串口组合预览仍可通过实际引脚网络驱动外部 LED。

这是静态时间采样，不是真正的串口或 MCU C++ 执行。对不支持的表达式、`analogRead`、`Serial.read`、嵌套控制流继续拒绝解析，日志中的 HTML 片段会安全转义，预览数据不写入工程 JSON。

### v0.4.0-alpha.4：有界 for 循环静态展开

新增第 15 个示例「Arduino D13 有界循环脉冲」，在代码面板中可以预览三次 D13 脉冲与串口日志。仅支持 `for(int i=0; i<N; i++) { ... }`，N 为 0–16 的整数字面量，循环体限于原有 D13、delay 和 Serial 白名单，总展开指令不超过 128 条。嵌套循环、条件分支、变量表达式和完整 AVR/C++ 执行均不支持；预览数据不写入工程 JSON。

### v0.4.0-alpha.5：优先修复基本连线

**在元件引脚上按住并拖到另一个引脚或面包板插孔，松开即可连线。** 绘制过程中显示实时导线、对齐参考线和目标吸附提示。仍支持“单击起点、单击终点”，点击空白处可增加导线折点（最多 32 个）；按 Escape 或「取消接线」可放弃草稿，不影响工程。面包板插孔选择采用随缩放自适应的屏幕像素判定，真实插入的元件画在面包板上层，避免引脚被遮盖。连线后不会强制进入端点重接模式，可以继续从已有引脚引出分支。选中既有导线可以重接两端，双击导线可加入折点。

导通完全由保存的引脚 ID、面包板内部导通组和插入接点确定；导线视觉交叉不会短接。新增从空白电路拖线构建完整 LED 回路、面包板吸附、撤销重做与非法重复接线的多浏览器回归测试。项目尚未达到完整 Tinkercad Circuits 功能对等。

### v0.4.0-alpha.6：手动布线方向与直角走线

从引脚拖线，或者点击起点、点空白处增加途径点、再点击终点。**新导线全程使用水平/垂直的正交路径**，不会因为手动加入折点而出现斜线。首次明显拖动时依据鼠标移动方向选定「横向优先」或「纵向优先」；布线过程中点击画布下方的方向按钮，即可立即反转走线转角，并锁定该选择。预览线、转角标记和引脚吸附提示会同步变化。

新增的可选 `routing` 属性保存在原有 v2 JSON 工程中；移动元件时重新计算直角路径，保留手动途径点。不含 `routing` 的旧工程保持原有走线外观，只有主动点击导线属性中的方向按钮才切换为新模式。导线方向与折点可撤销/重做，导通仍只由引脚 ID 决定。

元件库点击添加时优先找附近没有其他元件遮挡的位置，拖放仍尊重用户指定的坐标；增加引脚透明命中区域，改善密集插孔和触屏操作。

### v0.4.0-alpha.7：对照 Tinkercad 原版的连线细节

根据 Autodesk 官方指南和教学截图继续对齐：新导线**默认绿色**，顶部提供黑、红、橙、黄、绿、青、蓝、紫、粉、棕、灰、白等常用颜色；选择导线后可以按数字键 **0–9** 快速改色（数字与具体颜色的映射为本项目当前菜单顺序，未获得原版逐项核实）。**R 恢复为旋转所选元件**，不再错误地切换走线方向；原有横／纵优先方向按钮继续作为辅助工具保留。

将鼠标移至引脚会显示红色连接目标框及引脚名称；接线时显示淡蓝色横／竖对齐参考线和跟随光标的实色导线。点击空白处可以加入转折点；对于已有的线，可以**按住线身拖动生成新折点**，也可以双击线身后拖动；选中单个折点按 Delete 只删该折点，不会误删整根导线。撤销／重做按一次编辑为单位保存。

**空白画布拖拽为平移，Shift＋空白处拖拽为框选，F 为缩放适应内容**，并考虑手动布线的折点边界。工程仍使用 schema-v2，旧线的颜色、路径和电气连接兼容保留。

### v0.4.0-alpha.8：修复面包板遮线与导线层级

针对面包板挡住接线、导线在板面上无法选中的问题，将 SVG 渲染拆成固定层级：**面包板底板 → 已连接导线 → 仅插孔位置的命中与细边框 → 其他元件 → 折点／端点编辑手柄 → 接线预览及提示**。导线应能在面包板上正常显示与被选择，LED／电阻等实体元件仍显示在电线之上。

面包板插孔的前景透明命中圈缩小到孔附近，避免密集插孔吃掉整块板面上的导线点击；面包板空白区域仍可用屏幕像素半径吸附到最近真实插孔。不会修改原有 JSON 电路的导通关系或导线 ID，并新增三个浏览器的板面走线、真实插孔、元件遮挡、折点手柄与缩放回归测试。
